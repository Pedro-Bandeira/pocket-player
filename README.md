# PocketPlayer

PocketPlayer é um player de música portátil baseado em ESP32-S3.

## Hardware

- ESP32-S3
- LCD ILI9341 2.8"
- Touch FT6336G
- MicroSD
- Speaker
- Bluetooth
- Wi-Fi
